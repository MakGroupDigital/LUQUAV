# Logo LUQUAV — version modernisée

Même icône que le logo d’origine (chevron gris + chevron orange autour d’un losange), redessinée en vectoriel avec la même géométrie, des dégradés légers et des angles adoucis. Le mot « LUQUAV » est en Manrope ExtraBold (police des applications), converti en tracés : aucune police à installer.

| Fichier | Usage |
| --- | --- |
| `svg/luquav-logo-horizontal.svg` | Logo principal, fond clair |
| `svg/luquav-logo-horizontal-blanc.svg` | Logo principal, fond sombre |
| `svg/luquav-logo-vertical(-blanc).svg` | Version empilée (affiches, écrans d’accueil) |
| `svg/luquav-business-horizontal(-blanc).svg` | Sous-marque LUQUAV Business |
| `svg/luquav-logo-classique.svg` | Composition d’origine (texte sur l’icône), modernisée |
| `svg/luquav-icone.svg` | Icône seule, fond transparent |
| `svg/luquav-icone-app-nuit.svg` / `-blanc.svg` | Icône d’application |
| `svg/luquav-logo-mono-nuit.svg` / `-blanc.svg` | Impression une couleur, tampons, gravure |
| `svg/favicon.svg`, `png/favicon-*.png`, `png/apple-touch-icon.png`, `png/android-chrome-*.png` | Navigateurs et écrans d’accueil |

Couleurs : orange `#FFA623 → #EB850D`, gris `#B3B8C0 → #8C929B`, bleu nuit `#17304E` / `#0E1E36`.
Régénérer : `python make_logo.py <dossier>` (nécessite `fonttools` et la police Manrope).
